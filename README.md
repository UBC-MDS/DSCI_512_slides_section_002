# UBC DSCI 512 Section 002 Slides

This repository contains the slides for DSCI 512 (Algorithms and Data Structures), Section 002, for 2026 Winter Term 1. The instructor for this section is Sky (Kehan) Sheng.

## Site

Slides are built with [Quarto](https://quarto.org/) and published to GitHub Pages. To preview locally:

```bash
cd website
quarto preview
```
